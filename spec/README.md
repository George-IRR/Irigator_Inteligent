# Specificatii proiect

In acest folder tinem specificatiile si planul tehnic al proiectului, impartite in doua fisiere principale:

- `spec-manual.md` este fisierul de lucru pentru membrii echipei, unde oricine poate nota rapid idei noi, propuneri de implementare sau posibile directii pentru proiect, fara sa tina cont de formatare.
- `spec.md` este fisierul principal de specificatii, unde ideile discutate si partea de documentare sunt puse in ordine si formatate curat.

## Cum folosim sectiunea "De cercetat" din `spec-manual.md`

Cand cineva din echipa are o intrebare tehnica sau o idee despre care nu stim inca sigur cum trebuie implementata, o trece in lista `De cercetat:`.

Ca regula de lucru intre noi:
- Nu modificam ideile puse de colegi acolo, decat daca sunt greseli evidente de scriere sau de exprimare care fac textul greu de inteles.
- Dupa ce unul dintre noi cauta informatiile si face documentarea intr-un fisier dedicat in folderul `research/`, mutam punctul respectiv din `De cercetat:` in categoria potrivita din `spec-manual.md` (de exemplu la `Posibile implementari:`) si punem direct link catre fisierul din `research/` unde am scris concluziile.
